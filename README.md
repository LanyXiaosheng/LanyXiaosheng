## 📥 XMD · 帖子归档

<a href="https://github.com/LanyXiaosheng/x-post-markdown"><img src="assets/card-xmd.png" width="100%" alt="XMD：把 X 上的好内容留在本地，将帖子、长文和评论保存为 Markdown。"></a>

**把 X 帖子、长文和评论保存为本地 Markdown。** 支持单帖与批量导出，保留长文结构和图片链接；无需 X API Key，内容在浏览器本地处理，导出功能免费。<br>
**Save X posts, articles, and replies as local Markdown.** Export one post or a batch, keeping article structure and image links. Free exports, local processing, and no X API key required.
